# Input Parameters

SpecFWAT reads `DATA/fwat_params.yml` for simulation, measurements, gradient processing and model updates. This reference was checked on **2026-11-03** against the latest `devel` commit [`39a9a9b`](https://github.com/CompSeismoUT/SpecFWAT/commit/39a9a9b5b7b4cf55b6b327bc90b7ef4f1b6607c5). Parameter names and defaults below follow the [YAML reader][reader]; supported measurement numbers follow the [constants][constants] and [dispatcher][dispatcher].

<Callout type="info">
Download the complete [example `fwat_params.yml`](/fwat_params.yml). Its mesh, grid, sampling, filters and optimization settings are **example values**, not project-independent defaults. For choosing stages, joint weights and optimizer history, see [Inversion Strategy](/docs/inversion/strategy).
</Callout>

## Reading the configuration

Use uppercase keys and YAML booleans (`True`/`False`). Paths are relative to the project working directory unless absolute. Supply the section for every data type you run or enable in `POSTPROC.INV_TYPE`; omit unused simulation sections if desired. Every simulation section that is present is parsed, including its nested settings. Keep `MODEL_GRID`, `POSTPROC`, `MODEL_UPDATE` and `OUTPUT` in the file.

In the tables, **set explicitly** means that the reader does not supply a usable scientific default; copy and adapt the corresponding entry from the example. A listed **default** is an explicit fallback in the reader, not simply a value from a bundled test.

| Quantity | Units / ordering |
| --- | --- |
| `DT`, periods, arrival windows and time shifts | Seconds |
| Grid coordinates, grid spacing, `SIGMA_H/V` and tapers | Meters |
| Group velocities and LEQ `MIN_VELOCITY` | km/s |
| `MODEL_GRID` vectors | `[x, y, z]`, with negative `z` below the surface |
| `INV_TYPE`, `JOINT_WEIGHT` | Exactly three entries: `[noise, tele, leq]` |

<Callout type="warning">
Set `NOISE.IMEAS` explicitly. The current reader still falls back to `7` when it is omitted, but `7` is absent from the current measurement dispatcher and causes an unknown-measurement error. The downloadable example uses `13`; use `11` for a cross-correlation time shift.
</Callout>

## `NOISE` Section

```yaml filename="fwat_params.yml" copy
NOISE:
  MESH_PAR_FILE: DATA/meshfem3D_files/Mesh_Par_file
  SCOMPS: ['Z']
  RCOMPS: ['Z']
  CH_CODE: BX
  IMEAS: 13
  USE_RHO_SCALING: True
  NSTEP: 4500
  DT: 0.06
  SHORT_P: [6, 10, 20]
  LONG_P: [15, 25, 40]
  GROUPVEL_MIN: [2.3, 2.3, 2.5]
  GROUPVEL_MAX: [3.2, 3.5, 4.0]
  ADJ_SRC_NORM: False
  USE_NEAR_OFFSET: False
  SUPPRESS_EGF: False
  PRECOND_TYPE: 1
  SIGMA_H: 5000
  SIGMA_V: 5000
```

### Mesh and solver parameters

| Key | Meaning | Default |
| --- | --- | --- |
| `MESH_PAR_FILE` | SPECFEM3D internal mesher input; may differ between simulation types. | Set explicitly |
| `SCOMPS` | Ambient-noise virtual-source components. | Set explicitly |
| `RCOMPS` | Receiver components used in measurements, such as `['Z']`. | Set explicitly |
| `CH_CODE` | Channel prefix, e.g. `BX` gives `BXZ`. Must match observed SAC filenames. | Set explicitly |
| `NSTEP`, `DT` | Simulation sample count and time step; override the corresponding `Par_file` values for the selected type. | Set explicitly |
| `SHORT_P`, `LONG_P` | Lower and upper periods of each bandpass. Use positive periods with `SHORT_P < LONG_P`. | Set explicitly |
| `GROUPVEL_MIN`, `GROUPVEL_MAX` | Bounds used to select each band's surface-wave window. | Set explicitly |

`SHORT_P`, `LONG_P`, `GROUPVEL_MIN` and `GROUPVEL_MAX` must have the same nonzero length. Multiple entries are processed and summed **within one iteration**; they do not define an automatic sequence of inversion stages.

### Adjoint source

| Key | Meaning | Default |
| --- | --- | --- |
| `IMEAS` | Measurement number; see the [supported measurements](#supported-measurements) below. | Reader fallback `7` is unsupported; set explicitly |
| `ADJ_SRC_NORM` | Rescale each nonzero band's adjoint source to the largest band amplitude for a receiver/component before summing. | `False` |
| `USE_NEAR_OFFSET` | `False` enables the distance rejection below; `True` keeps near offsets. | `False` |
| `SUPPRESS_EGF` | `False` differentiates the observed cross-correlation in time; `True` skips differentiation for data already in EGF form, including synthetic tests. | Set explicitly |

The [noise preprocessing implementation][noise] sets, for distance $\Delta$ in km and velocities in km/s,

```math
T_{start}=\frac{\Delta}{U_{max}}-\frac{T_{long}}{2},\qquad
T_{end}=\frac{\Delta}{U_{min}}+\frac{T_{long}}{2}.
```

The interval is clipped to the available simulation. With `USE_NEAR_OFFSET: False`, a trace is rejected when

```math
\Delta < \frac{U_{max}+U_{min}}{2}\,T_{long}.
```

This is one wavelength estimated from the mean group velocity and the long-period cutoff. Older descriptions of a half-wavelength threshold do not match this revision.

### Gradient processing parameters

| Key | Meaning | Default |
| --- | --- | --- |
| `PRECOND_TYPE` | `1`: sum of absolute event Hessian kernels. Post-processing also implements `0` for the absolute value after summation; see the limitation below. The result is normalized, water-leveled and inverted. | Set explicitly |
| `SIGMA_H`, `SIGMA_V` | Horizontal and vertical PDE smoothing lengths. | Set explicitly |
| `USE_RHO_SCALING` | In post-processing, replace the smoothed `rhop` gradient by `0.33` times the smoothed `beta` gradient. | `True` |

The forward setup enables approximate-Hessian kernel generation only for `PRECOND_TYPE: 1` in this revision. Although post-processing accepts `0`, a normal run with `0` does not generate the Hessian input it expects. Use `1` for the acceleration-based preconditioner unless that source limitation is resolved.

## `TELE` Section

```yaml filename="fwat_params.yml" copy
TELE:
  TELE_TYPE: 1
  MESH_PAR_FILE: DATA/meshfem3D_files/Mesh_Par_file
  RCOMPS: ['Z', 'R']
  CH_CODE: BX
  INJECTION_TYPE: 1
  SAVE_FK: True
  COMPRESS_LEVEL: 0
  # AXISEM_BASE_PATH: /path/to/axisem_db
  SUPPRESS_STF: True
  USE_LOCAL_STF: False
  NSTEP: 3000
  DT: 0.025
  SHORT_P: [2]
  LONG_P: [40]
  TIME_WIN: [-5, 45]
  PRECOND_TYPE: 2
  SIGMA_H: 5000
  SIGMA_V: 5000
  RF:
    F0: [1.0]
    MAXIT: 200
    MINDERR: 0.001
    TSHIFT: 5.0
```

### Adjoint source and data type

The shared mesh, component, sampling and smoothing keys have the meanings above. Teleseismic processing uses **one band**, `SHORT_P[0]` and `LONG_P[0]`; provide one entry in each list. Change the lists between runs to implement a period schedule.

| Key | Meaning | Default |
| --- | --- | --- |
| `TELE_TYPE` | `1`: waveform difference (`tele`); `2`: receiver-function difference (`rf`); `3`: cross-convolution (`telecc`). Also selects `src_rec/sources_{dat_type}.dat`. | Set explicitly |
| `TIME_WIN` | Exactly two offsets around the reference direct P arrival, `[start, end]`. | Set explicitly |
| `PRECOND_TYPE` | `2`: normalized depth scaling proportional to `abs(z)`; `3`: proportional to `sqrt(abs(z))`, with near-surface regularization. | Set explicitly |
| `INJECTION_TYPE` | `1`: FK injection; `2`: AxiSEM injection. | `1` |
| `AXISEM_BASE_PATH` | Base directory of per-event AxiSEM coupling data, read when `INJECTION_TYPE: 2`. | Set explicitly for AxiSEM |
| `SAVE_FK` | Reuse saved FK boundary wavefields for FK injection. | `True` |
| `COMPRESS_LEVEL` | HDF5 deflate compression for saved FK files: `0` disables compression; `1`–`9` request increasing compression. | `0` |
| `SUPPRESS_STF` | In forward-only SAC export, `False` convolves synthetics with `src_rec/STF_{event_name}.sac`; `True` skips that convolution. | `True` |
| `USE_LOCAL_STF` | Parsed and broadcast, but not used by a processing branch in this revision. | Set explicitly to `False` |

`TELE.IMEAS` and `TELE.USE_RHO_SCALING` are not YAML options in this reader: the teleseismic path selects its own measurement implementation and disables density scaling.

Saved FK files are stored as `{LOCAL_PATH}/FK_wavefield_{event_name}/procXXXXXX_fk_wavefield.h5`, where `LOCAL_PATH` comes from `DATA/Par_file`. Cache validation checks file existence; use a fresh cache when changing the mesh, partitioning, sampling or FK model. See the [FK coupling source][fk].

<Callout type="info">
`SUPPRESS_STF` does not disable the internal STF estimation in teleseismic waveform measurement. `USE_LOCAL_STF` currently does not switch that estimator to a supplied STF. These behaviors are distinct in [teleseismic preprocessing][tele]. AxiSEM is exposed by the simulation interface, but the current measurement paths still contain FK travel-time/model dependencies; verify the complete measurement path before using it for inversion.
</Callout>

### Receiver function parameters

Keep the `RF` dictionary whenever a `TELE` section is present: the reader accesses it even when `TELE_TYPE` is `1` or `3`. Values are used for iterative deconvolution when receiver functions are calculated.

| Key | Meaning | Default |
| --- | --- | --- |
| `RF.F0` | List of Gaussian widths; RF measurements loop over these widths. This is independent of the single teleseismic bandpass. | Set explicitly |
| `RF.MAXIT` | Maximum iterative-deconvolution iterations. | Set explicitly |
| `RF.MINDERR` | Stopping tolerance on the change in normalized residual error, expressed as a percentage by the deconvolution routine. | Set explicitly |
| `RF.TSHIFT` | Time shift applied to the receiver function. | Set explicitly |

## `LEQ` Section

Local earthquake adjoint tomography uses `-s leq`, `src_rec/sources_leq.dat` and per-event `CMTSOLUTION` files. The shared solver and gradient parameters have the meanings listed for `NOISE`, with these reader defaults:

| Key | Default |
| --- | --- |
| `IMEAS` | `13` (multitaper time shift) |
| `CH_CODE` | `BX` |
| `ADJ_SRC_NORM` | `False` |
| `USE_RHO_SCALING` | `True` |

```yaml filename="fwat_params.yml" copy
LEQ:
  MESH_PAR_FILE: DATA/meshfem3D_files/Mesh_Par_file
  NSTEP: 3000
  DT: 0.05
  PRECOND_TYPE: 1
  IMEAS: 13
  RCOMPS: ['Z', 'R', 'T']
  CH_CODE: BX
  SHORT_P: [2, 5]
  LONG_P: [10, 20]
  ADJ_SRC_NORM: False
  USE_RHO_SCALING: True
  SIGMA_H: 5000
  SIGMA_V: 5000
  WINDOW:
    WIN_TYPE: 3
    WIN_TYPE_3:
      GROUPVEL_MIN: [2.3, 2.3]
      GROUPVEL_MAX: [3.5, 4.0]
```

### `WINDOW` Sub-section

Supply `WINDOW` and the `WIN_TYPE_n` dictionary selected by `WIN_TYPE`. The reader defaults `WIN_TYPE` to `1` within an existing `WINDOW` section; this still requires `WIN_TYPE_1`.

| `WIN_TYPE` | Selector | Required nested dictionary |
| --- | --- | --- |
| `1` | Sliding cross-correlation selector with correlation, shift, length, SNR and observed/synthetic energy tests. | `WIN_TYPE_1` |
| `2` | FLEXWIN-style STA/LTA selector and waveform-quality tests. | `WIN_TYPE_2` |
| `3` | Group-velocity window, using the same formula as noise. | `WIN_TYPE_3` |
| `4` | Fixed window around a predicted named phase. | `WIN_TYPE_4` |

For types `1` and `2`, the reference phase is fixed to `P`. Period factors below refer to the band's **short-period cutoff** (`SHORT_P`), not an independently estimated dominant period. `MIN_VELOCITY` sets the late end of the search interval.

#### WIN_TYPE = 1

These are the explicit YAML-reader defaults for `WIN_TYPE_1`:

```yaml copy
WINDOW:
  WIN_TYPE: 1
  WIN_TYPE_1:
    SLIDING_WIN_LEN_FAC: 2.0
    MIN_VELOCITY: 2.4
    THRESHOLD_CORR: 0.8
    THRESHOLD_SHIFT_FAC: 0.3
    JUMP_FAC: 0.1
    MIN_WIN_LEN_FAC: 1.5
    MIN_SNR_WINDOW: 5.0
    MIN_ENERGY_RATIO: 5.0
    MIN_PEAKS_TROUGHS: 3
    IS_SPLIT_PHASES: False
```

`SLIDING_WIN_LEN_FAC` sets sliding-window length. `THRESHOLD_CORR` is the minimum correlation and `THRESHOLD_SHIFT_FAC` limits absolute time shift. `JUMP_FAC` sets the buffer for grouping windows. `MIN_WIN_LEN_FAC` and `MIN_PEAKS_TROUGHS` reject short or featureless windows. `MIN_SNR_WINDOW` sets the amplitude-to-noise threshold. Despite its name, `MIN_ENERGY_RATIO` bounds the **observed/synthetic** window-energy ratio to `[1/value, value]`; it is not a signal/noise energy threshold. `IS_SPLIT_PHASES` enables the selector's window-splitting step.

#### WIN_TYPE = 2

These are the explicit YAML-reader defaults for `WIN_TYPE_2`:

```yaml copy
WINDOW:
  WIN_TYPE: 2
  WIN_TYPE_2:
    MIN_VELOCITY: 2.4
    MIN_WIN_LEN_FAC: 1.5
    THRESHOLD_CORR: 0.8
    THRESHOLD_SHIFT_FAC: 2.0
    MIN_PEAKS_TROUGHS: 3
    THRESHOLD_DLNA: 1.0
    MIN_SNR_WINDOW: 5.0
    IS_SPLIT_PHASES: False
    MAX_TIME_BEFORE_FIRST_ARRIVAL: 10.0
    STALTA_WATER_LEVEL: 0.08
    C_0: 1.0
    C_2: 0.0
    C_3A: 4.0
    C_3B: 2.5
    C_4A: 2.0
    C_4B: 6.0
```

The shared thresholds have the meanings above. `THRESHOLD_DLNA` bounds logarithmic amplitude difference; `MAX_TIME_BEFORE_FIRST_ARRIVAL` sets how far before the P arrival the search can start. `STALTA_WATER_LEVEL` and the `C_*` coefficients tune the STA/LTA-based criteria. Consult the [selector implementations][windows] when adjusting these coefficients.

#### WIN_TYPE = 3

Provide one `GROUPVEL_MIN` and `GROUPVEL_MAX` per filter band, as in the LEQ example. Their lengths must equal `SHORT_P`'s length. Keep `LONG_P` the same length as `SHORT_P` as well.

#### WIN_TYPE = 4

```yaml copy
WINDOW:
  WIN_TYPE: 4
  WIN_TYPE_4:
    PHASE: P
    TIME_WIN: [-5, 45]
```

`PHASE` defaults to `P`. Set `TIME_WIN` explicitly to two offsets in seconds around the predicted arrival. Use a phase supported by the compiled travel-time tables. Windows are clipped to the simulation interval.

## `ADJOINT_SOURCE` Section

This section configures the built-in measurement routines. Include the full section from the downloadable example so that the intended taper and acceptance/error thresholds are explicit. The old external `measure_adj` numbering is not the current SpecFWAT measurement API.

### Supported measurements

The general noise/LEQ dispatcher accepts the following values:

| `IMEAS` | Measurement |
| --- | --- |
| `1` | Waveform difference |
| `4` | Exponentiated phase misfit |
| `5` | Cross-correlation coefficient misfit |
| `11` | Cross-correlation time shift |
| `12` | Cross-correlation logarithmic amplitude ratio |
| `13` | Multitaper time shift, with cross-correlation fallback when MT quality criteria fail |
| `14` | Multitaper logarithmic amplitude ratio, with cross-correlation fallback |

The constants also define `2` for waveform convolution and `3` for receiver functions, but the general noise/LEQ dispatcher stops if either is selected; they require specialized multicomponent routines. Select teleseismic receiver functions or cross-convolution through **`TELE_TYPE: 2` or `3`**, respectively. `TELE_TYPE` numbers and `IMEAS` numbers are different settings.

### Taper and cross-correlation settings

| Key | Meaning | Default / requirement |
| --- | --- | --- |
| `ITAPER_TYPE` | `1`: Hanning; `2`: Hamming; `3`: cosine; `4`: cosine to the tenth power. | Set explicitly when `ADJOINT_SOURCE` is present |
| `TAPER_PERCENTAGE` | Fraction controlling taper length within each measurement window. | `0.3` |
| `CC.TSHIFT_LIM` | Two time-shift acceptance bounds. | Retains `[-5, 5]` when absent |
| `CC.DLNA_LIM` | Two logarithmic-amplitude acceptance bounds. | Retains `[-1.5, 1.5]` when absent |
| `CC.CC_MIN` | Minimum accepted correlation coefficient. | Set explicitly when `CC` is present |
| `CC.DT_SIGMA_MIN` | Floor for time-shift uncertainty. | Set explicitly when `CC` is present |
| `CC.DLNA_SIGMA_MIN` | Floor for logarithmic-amplitude uncertainty. | Set explicitly when `CC` is present |

### Multitaper and envelope settings

The following defaults are supplied when the `MT`/`ENV` dictionaries are present:

| Key | Meaning | Reader default |
| --- | --- | --- |
| `MT.NUM_TAPER` | Number of tapers. | `5` |
| `MT.MT_NW` | Time-bandwidth parameter; half-bandwidth is `MT_NW * df`. | `4.0` |
| `MT.PHASE_STEP` | Phase-jump threshold used for cycle-skip correction. | `1.5` |
| `MT.TRANSFUNC_WATERLEVEL` | Transfer-function water level. | `1e-10` |
| `MT.WATER_THRESHOLD` | Spectral selection threshold. | `0.02` |
| `MT.DT_FAC` | Period-scaled limit used for multitaper acceptance. | `2.0` |
| `MT.ERR_FAC` | Error threshold used for multitaper acceptance. | `2.0` |
| `MT.DT_MAX_SCALE` | Scale in the maximum permitted shift calculation. | `3.5` |
| `MT.MIN_CYCLE_IN_WINDOW` | Minimum cycles in a measurement window. | `3` |
| `MT.USE_MT_ERROR` | Use multitaper error estimates in weighting. | `False` |
| `ENV.WTR_ENV` | Water level used by the envelope-based calculation. | `0.2` |

`MT.ERR_FAC` is a source-level inconsistency: omitting it from an existing `MT` dictionary uses **`2.0`**, while omitting the dictionary retains the `ADJConfig` initializer **`2.5`**. The example sets `2.5` explicitly, matching the bundled measurement examples. Do not treat initialized type values as identical to all YAML-reader defaults.

## `MODEL_GRID` Section

The regular grid is the common space for model updates and for combining gradients from different simulation meshes.

```yaml copy
MODEL_GRID:
  REGULAR_GRID_MIN_COORD: [833950, -44274.0, -80000]
  REGULAR_GRID_INTERVAL: [2000, 2000, 1000]
  REGULAR_GRID_SIZE: [104, 48, 81]
```

Set all three vectors explicitly, with exactly three entries each. `REGULAR_GRID_MIN_COORD` is the first `[x,y,z]` point; `REGULAR_GRID_INTERVAL` is positive point spacing; `REGULAR_GRID_SIZE` is the number of points. The maximum coordinate along each axis is `min + (size - 1) * interval`.

Choose spacing fine enough to retain the mesh-resolved gradient. Ensure the grid covers the meshes used by all enabled data types. The [model preparation page](/docs/preparation/model) describes the HDF5 model format.

## `POSTPROC` Section

```yaml copy
POSTPROC:
  INV_TYPE: [False, True, False]
  JOINT_WEIGHT: [0.5, 1.0, 0.5]
  NORM_TYPE: 1
  TAPER_H_SUPPRESS: 5000
  TAPER_H_BUFFER: 15000
  TAPER_V_SUPPRESS: 0
  TAPER_V_BUFFER: 0
  IS_PRECOND: False
```

| Key | Meaning | Default |
| --- | --- | --- |
| `INV_TYPE` | Enable gradient processing for `[noise, tele, leq]`; enable at least one. More than one activates joint inversion. | Set explicitly |
| `JOINT_WEIGHT` | Relative weights of the normalized type gradients, in the same order. | Set explicitly |
| `NORM_TYPE` | Joint normalization: `1` reference-gradient infinity norm; `2` reference total misfit; `3` reference-gradient standard deviation. | `1` |
| `TAPER_H_SUPPRESS`, `TAPER_V_SUPPRESS` | Horizontal/vertical boundary regions where the gradient is suppressed. | `0` |
| `TAPER_H_BUFFER`, `TAPER_V_BUFFER` | Widths over which the boundary taper transitions. | `0` |
| `IS_PRECOND` | `True`: precondition kernels before smoothing. `False`: save `optimize/hess_inv_Mxx.h5` for optimizer direction scaling. | Set explicitly |

For joint inversion, the [post-processing implementation][post] forms `sum(JOINT_WEIGHT[type] * gradient[type] / reference_scale[type])`. These weights do not have to sum to one. In a single-type inversion, the joint normalization/weighting step is skipped.

For L-BFGS (`OPT_METHOD: 2`), reference scales come from the iteration named by `ITER_START`; for SD and CG they come from `M00`. Preserve the corresponding per-type gradients or misfits. Reference scales must be nonzero. Boundary tapers are particularly important for teleseismic updates to preserve consistency with the external injection model.

With `IS_PRECOND: False`, SD, CG and L-BFGS use the saved scaling field; it is not exclusive to L-BFGS. In a joint inversion the current code saves this field from the **teleseismic** branch, skipping noise and LEQ. For a noise+LEQ joint inversion without TELE, use direct preconditioning (`IS_PRECOND: True`) or resolve that implementation limitation before running. See [Inversion Strategy](/docs/inversion/strategy) for joint-inversion and line-search limitations.

## `MODEL_UPDATE` Section

```yaml copy
MODEL_UPDATE:
  INIT_MODEL_PATH: initial_model.h5
  MODEL_TYPE: 1
  OPT_METHOD: 2
  ITER_START: 0
  LBFGS_M_STORE: 5
  MAX_SLEN: 0.02
  MAX_SHRINK: 0.618
  MAX_SUB_ITER: 10
  DO_LS: False
  C1: 0.01
  VPVS_RATIO_RANGE: [1.3, 2.5]
```

| Key | Meaning | Default |
| --- | --- | --- |
| `INIT_MODEL_PATH` | Initial HDF5 model, interpolated onto `MODEL_GRID` at `M00` and saved to `optimize/model_M00.h5`. | Set explicitly |
| `MODEL_TYPE` | `1`: `vp, vs, rho`; `2`: `vp, vs, rho, gcp, gsp`. | `1` |
| `OPT_METHOD` | `1`: steepest descent; `2`: L-BFGS; `3`: conjugate gradient. | Set explicitly |
| `ITER_START` | First iteration of the current optimizer-history stage. The iteration passed with `-m Mxx` must not be smaller. | Set explicitly |
| `LBFGS_M_STORE` | Maximum previous iteration pairs used by L-BFGS. | Set explicitly |
| `MAX_SLEN` | Initial trial step, or fixed step with `DO_LS: False`, for a direction normalized to unit maximum absolute value. | Set explicitly |
| `MAX_SHRINK` | Multiplicative reduction applied after a failed backtracking trial; choose between zero and one. | Set explicitly |
| `MAX_SUB_ITER` | Maximum number of line-search trials. Exhausting it aborts optimization. | Set explicitly |
| `DO_LS` | Recompute forward measurements and backtrack when `True`; otherwise use the fixed step. | Set explicitly |
| `C1` | Sufficient-decrease coefficient in the backtracking acceptance test. | `0.01` |
| `VPVS_RATIO_RANGE` | Exactly two bounds on `vp/vs`. The update clips `vp` to enforce these bounds. | Set explicitly |

Velocity and density updates are multiplicative: `m_new = m * exp(step * direction)`. Thus `MAX_SLEN: 0.02` permits about a 2% change before ratio clipping for an active isotropic parameter at the largest direction amplitude. The anisotropic `gcp/gsp` updates are additive. Successful optimization writes the next model both to `optimize/model_Mxx.h5` and to `{TOMOGRAPHY_PATH}/tomography_model.h5` for the next mesh/database generation (`TOMOGRAPHY_PATH` is configured in `DATA/Par_file`, commonly `DATA/tomo_files/`).

`ITER_START` does not set the shell loop's starting index. It sets the history boundary: L-BFGS and CG use steepest descent at that iteration. When changing filters, data, weights or parameter blocks, start a new stage deliberately and retain the corresponding model and reference files. There is no YAML iteration scheduler in this revision.

### Azimuthal anisotropy and alternating updates

For `MODEL_TYPE: 2`, include this additional dictionary:

```yaml copy
MODEL_UPDATE:
  MODEL_TYPE: 2
  MODEL_TYPE_2:
    ALT_INV: True
    CURRENT_INV_TYPE: 1
  # Include the remaining MODEL_UPDATE entries shown above.
```

`ALT_INV` defaults to `False`, which updates all five parameters. With `ALT_INV: True`, `CURRENT_INV_TYPE: 1` updates only `vp/vs/rho`, and `2` updates only `gcp/gsp`; its default is `1`. The driver does **not** change `CURRENT_INV_TYPE` automatically. The stored model uses the normalized azimuthal parameters `gcp/gsp`, not independent `L, N, Gc, Gs` fields. Prepare `/gcp` and `/gsp` explicitly with the same array shape as `/vp` (zero arrays for an isotropic starting model). The initializer attempts a zero fallback when they are missing, but constructs that fallback on the inversion-grid dimensions; it is unsafe to rely on it when the input model uses different axes or dimensions.

<Callout type="warning">
The current temporary-model construction used by line search does not preserve the inactive block when alternating updates are enabled. Use fixed steps (`DO_LS: False`) for this configuration until that code path is corrected. Review the [strategy and implementation limits](/docs/inversion/strategy) before enabling line search, especially for joint inversion.
</Callout>

The [optimizer implementation][optimizer] is the authority for update formulas and history behavior.

## `OUTPUT` Section

All six flags default to **`False`** when omitted from the required `OUTPUT` dictionary. The downloadable example turns several on for inspection.

| Flag | Effect when `True` |
| --- | --- |
| `IS_OUTPUT_PREPROC` | Write preprocessed observed/synthetic SAC diagnostics under `solver/{model}.{dat_type}/{event}/OUTPUT_FILES/`. |
| `IS_OUTPUT_ADJ_SRC` | Write per-band SAC adjoint-source diagnostics under the event `SEM/` directory. This flag does not disable the adjoint sources required by the solver. |
| `IS_OUTPUT_EVENT_KERNEL` | Retain per-event `EKERNEL/` files after post-processing. Retain them when planning to repeat kernel summation. |
| `IS_OUTPUT_SUM_KERNEL` | Write summed GLL kernels under `optimize/SUM_KERNELS_{model}/`, or `optimize/SUM_KERNELS_{model}_{simu_type}/` in joint inversion. |
| `IS_OUTPUT_INV_GRID` | Parsed and broadcast, but no output operation uses this flag in this revision. |
| `IS_OUTPUT_DIRECTION` | Write `optimize/direction_{model}.h5`. |

Model and regular-grid gradient files needed by optimization are written independently of these diagnostic flags. With `DO_LS: True`, summed kernels are also written even if `IS_OUTPUT_SUM_KERNEL` is `False`.
