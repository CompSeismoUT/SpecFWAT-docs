## Working directory and configuration

Run all commands from the example directory after [building SpecFWAT](/docs/installation/config):

```bash copy
cd tests/toy_example_noise
```

Use the example's `DATA/Par_file` and `DATA/fwat_params.yml`. The supplied mesh is partitioned into 8 MPI processes (`NPROC_XI: 4`, `NPROC_ETA: 2`, `NPROC: 8`). The current noise example uses these measurement and inversion settings:

```yaml copy
NOISE:
  IMEAS: 13
  SUPPRESS_EGF: True
POSTPROC:
  INV_TYPE: [True, False, False]
MODEL_UPDATE:
  OPT_METHOD: 2
  ITER_START: 0
  DO_LS: False
```

This is an excerpt from the full configuration, not a replacement file. `IMEAS: 13` selects multitaper travel-time measurements. `SUPPRESS_EGF: True` is appropriate for the synthetic Green's-function data generated below. The example filters three bands, with `SHORT_P: [3, 7, 12]` and `LONG_P: [10, 12, 20]`.

## Generate synthetic data
To generate synthetic data, we need to run the forward simulation using SpecFWAT. Run `00_forward.sh` to generate synthetic data for the target model. The synthetic data is saved in the `fwat_data` folder.

```bash filename="00_forward.sh" copy showLineNumbers
#!/bin/bash
set -e

mkdir -p DATABASES_MPI
mkdir -p OUTPUT_FILES

NPROC=`grep ^NPROC DATA/Par_file | grep -v -E '^[[:space:]]*#' | cut -d = -f 2 | cut -d \# -f 1`

cp target_model.h5 DATA/tomo_files/tomography_model.h5
# Run Forward to generate data
mpirun -np $NPROC ../../bin/xfwat_mesh_databases -s noise
mpirun -np $NPROC ../../bin/xfwat_fwd_measure_adj -m M00 -s noise -r 1

```

## Conduct the inversion
Run `01_run_this_test.sh` to perform 15 model updates (`M00` through `M14`). Each successful optimizer call writes the next model, so the final output is `optimize/model_M15.h5`.

```bash filename="01_run_this_test.sh" copy showLineNumbers
#!/bin/bash
set -e

NPROC=`grep ^NPROC DATA/Par_file | grep -v -E '^[[:space:]]*#' | cut -d = -f 2 | cut -d \# -f 1`

# Run Inversion

for it in `seq 0 14`; do
    MODEL=`printf "M%02d" $it`
    if [ $it -eq 0 ]; then
        cp initial_model.h5 DATA/tomo_files/tomography_model.h5
    fi
    mpirun -np $NPROC ../../bin/xfwat_mesh_databases -s noise
    mpirun -np $NPROC ../../bin/xfwat_fwd_measure_adj -m $MODEL -s noise -r 3
    mpirun -np $NPROC ../../bin/xfwat_post_proc -m $MODEL
    mpirun -np $NPROC ../../bin/xfwat_optimize -m $MODEL
done
```

The run modes are `-r 1` for generating observations and `-r 3` for forward simulation, measurement, and adjoint simulation. Post-processing reads the active data types from `POSTPROC.INV_TYPE`; keep only noise enabled for this example. `DO_LS: False` means the example uses the configured fixed step length.

See the source [forward script](https://github.com/CompSeismoUT/SpecFWAT/blob/39a9a9b5b7b4cf55b6b327bc90b7ef4f1b6607c5/tests/toy_example_noise/00_forward.sh), [inversion script](https://github.com/CompSeismoUT/SpecFWAT/blob/39a9a9b5b7b4cf55b6b327bc90b7ef4f1b6607c5/tests/toy_example_noise/01_run_this_test.sh), and [example parameters](https://github.com/CompSeismoUT/SpecFWAT/blob/39a9a9b5b7b4cf55b6b327bc90b7ef4f1b6607c5/tests/toy_example_noise/DATA/fwat_params.yml).
