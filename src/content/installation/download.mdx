# Download Source Code

These pages follow the `devel` branch of [SpecFWAT](https://github.com/CompSeismoUT/SpecFWAT/tree/devel). Clone that branch and its pinned submodules:

```bash copy
git clone --branch devel --recurse-submodules https://github.com/CompSeismoUT/SpecFWAT.git
cd SpecFWAT
```

The two submodules are `src/specfem3d` and `external_libs/yaml-cpp`. Their URLs are recorded in `.gitmodules`. CMake also runs `git submodule update --init` unless `NO_UPDATE_SUBMODULE` is enabled.

## Update an existing checkout

From a clean checkout on `devel`, update the parent repository and then synchronize the submodules to its recorded revisions:

```bash copy
git switch devel
git pull --ff-only
git submodule sync --recursive
git submodule update --init --recursive
```

<Callout type='info'>
Use the submodule revisions recorded by SpecFWAT. Updating a submodule independently to its branch tip can select a solver version that differs from the one used by the parent repository.
</Callout>
