# Build and Compilation
import { Steps, Table, Tabs, Callout } from 'nextra/components';

SpecFWAT is built using CMake, a cross-platform build system. The following instructions will guide you through the process of building SpecFWAT on your system.

<Steps>
  ## Create a build directory
  ```bash copy
  mkdir build && cd build
  ```

  ## Configure the build
  Basically, you can use the following command to configure the build:
  ```bash copy
  cmake ..
  ```
</Steps>


## More options

### Specify the compiler

If you have multiple compilers installed, you can specify the Fortran and C compilers using the `FC` and `CC` options, respectively.

<Tabs items={["Niagara@CCDB", "Trillium@CCDB"]}>
  <Tabs.Tab>
    ```bash copy
    CC=icc CXX=icpc FC=mpifort MPIFC=mpifort cmake ..
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    ```bash copy
    CC=icc CXX=icpc FC=ifort MPIFC=mpiifort cmake .. -DUSE_CUDA=on -DCUDA_ARCH=12 
    ```
  </Tabs.Tab>
</Tabs>


### Specify HDF5 library

If the HDF5 library is installed in a non-standard location, you can specify the path to the HDF5 library using the `HDF5_ROOT` option. For example:

```bash copy
cmake -DHDF5_ROOT=/path/to/hdf5 ..
```

For example, to enable CUDA support and set the architecture to Ampere (A100), you can use the following command:

```bash copy
cmake -DUSE_CUDA=on -DCUDA_ARCH=11 ..
```

<Callout type="info">
More type of GPU cards can be found on the Nvidia [CUDA GPU Compute Capability](https://developer.nvidia.com/cuda-gpus) page.
</Callout>

## Compilation
After configuring the build, you can compile SpecFWAT using the following command:

```bash copy
cmake --build . --parallel 4
```

Executables are written to the source checkout's `bin/` directory. Run the example scripts from their own `tests/toy_example_*` directory so that paths such as `../../bin/xfwat_optimize` resolve correctly.

## Additional CMake options

| Option | Default | Purpose |
| --- | --- | --- |
| `NO_UPDATE_SUBMODULE` | `OFF` | Skip automatic submodule initialization when set to `ON`; initialize the pinned submodules yourself first. |
| `USE_EXTERNAL_LIBS` | `ON` | Use the bundled `yaml-cpp`; with `OFF`, CMake tries an installed `yaml-cpp` version 0.8 or later before falling back to the bundled copy. |
| `USE_HDF5` | `ON` | Enable HDF5 support, used for regular-grid models and inversion outputs. |
| `ENABLE_DOUBLE_PRECISION` | `OFF` | Build the solver with double precision. |
| `DEBUG_MODE` | `OFF` | Append the compiler-specific debug flags configured by the project. |

These options are defined in the [top-level CMake file](https://github.com/CompSeismoUT/SpecFWAT/blob/39a9a9b5b7b4cf55b6b327bc90b7ef4f1b6607c5/CMakeLists.txt).
